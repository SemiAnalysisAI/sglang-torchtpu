## 3. Rules

### PLC: Placement & core/plugin boundary (14)

### XBE: Other-backend / GPU regression safety (5)

| ID | Sev | Rule | Why | Evidence | Freq | Check |
|---|---|---|---|---|---|---|

## 5. What gets PRs blocked, and the evidence reviewers expect

### 5.1 What gets PRs blocked (CHANGES_REQUESTED, closed, or approval withheld)
- [ ] **A non-extensible or hacky seam:** monkeypatch, scattered `is_tpu`, core importing the plugin, TPU logic in shared files. → redesign through a hook (#15, #38, #661, #713, #1046, #1178). PLC-*
- [ ] **A silent-correctness risk:** an incomplete compile key, padded rows aliasing live KV, missing spec headroom, early page release, removed guards (#10, #5, #198, #427, #1082). CMP-7, KVS-*, SCH-1
- [ ] **A rank-divergent program, or a collective that can hang** (#279, #597, #854, #1229). DST-1/2
- [ ] **A serving-time recompile path or a precompile coverage gap** (#196, #364, #459). CMP-1
- [ ] **Tests that pass on revert, or no TPU coverage for a device change** (#198, #332 "I will LGTM then", #222, #13). TST-1/2
- [ ] **No end-to-end evidence, or numerics not isolated** (#57 "doesn't solve the problem for me", #222 prajjwal1). EVD-2
- [ ] **A perf feature or kernel that doesn't beat its baseline** (#156 FP4 5–8× slower, #44, #990 device idle 5→14%). EVD-1, KRN-3
- [ ] **A refactor that changes behavior, or a PR too big or mixed** (#612, #460, #222 split). EVD-3
- [ ] **Shared-path change with GPU impact and no GPU validation** (#791, #854, #1228). XBE-*
- [ ] **Red CI, or required lanes not run on the head** (#136 "get lint/CI working first", #1229). TST-6
- [ ] **A workaround that masks the real bug** (#637 closed, #102 closed). EVD-11, PLC-3

### 5.2 Evidence reviewers expect in the PR body
- [ ] Motivation, design, and which seam (§2) was used. An unavoidable core branch has an upstream seam issue and a debt-baseline note.
- [ ] Exact launch and bench commands, model, chip and topology, TP/EP/DP, ISL/OSL/concurrency, wheel and SHAs (EVD-1).
- [ ] A before/after table vs main, with cold compile and warmup separated from steady state (EVD-1).
- [ ] An accuracy eval with adequate n, isolating the new path, plus an ablation for bug fixes (EVD-2).
- [ ] Recompile stats: zero post-warmup compiles, before vs after (EVD-12).
- [ ] The name of the regression test that fails on main (TST-1).
- [ ] TPU CI lanes green on the head; a GPU run if shared code changed behavior (TST-6, XBE-4).
- [ ] For pin bumps, shared backends or upstream syncs: the 480B recipe before/after (EVD-9).
- [ ] A "Not run / Not in this PR" section, and TODO(issue#) for deferrals (EVD-6, EVD-7).
